## Random Password Generator

A beginner-friendly command-line application built with Python. The program generates strong random passwords based on the user's desired password length. Users can also choose whether to include special characters for enhanced password security.

## Features

- Generate random passwords of any length (minimum 8 characters).
- Option to include special characters.
- Uses uppercase and lowercase letters.
- Includes numeric digits.
- Validates password length.
- Handles invalid numeric input using exception handling.
- Simple and user-friendly command-line interface.

## Technologies & Concepts Used

- Python
- random Module
- string Module
- Loops
- Conditional Statements
- Exception Handling (try-except)
- String Manipulation

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program:

```bash
python Task_3.py
```
